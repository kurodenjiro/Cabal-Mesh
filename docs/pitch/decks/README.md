# Pitch decks — source

Two decks, one shared theme, both rendered with [pptxgenjs](https://gitbrent.github.io/PptxGenJS/).

| File | Renders | Slides |
| --- | --- | --- |
| `build-product.js` | `docs/pitch/CabalMesh-Product.pptx` | 14 — what CabalMesh is, what runs today, and the two planned boxes |
| `build-roadmap.js` | `docs/pitch/CabalMesh-Roadmap.pptx` | 11 — product & growth strategy: trust → demand → economy |
| `build-pitch.js` | `docs/pitch/CabalMesh-Pitch.pptx` | 7 — investor pitch: name · problem · solution · market · GTM · traction · team |
| `build-onepager.js` | `docs/pitch/CabalMesh-Project-Plan-1page.pdf` | 1 — A4 portrait project plan, via `.build/` + LibreOffice |
| `theme.js` | — | tokens + primitives only; no content, no slide knows another slide |

```bash
cd docs/pitch/decks && npm install
node build-product.js
node build-roadmap.js
node build-pitch.js
node build-onepager.js   # writes .build/*.pptx — convert to PDF below
```

PDF companions (optional, needs LibreOffice):

```bash
soffice --headless --convert-to pdf --outdir docs/pitch docs/pitch/CabalMesh-Product.pptx docs/pitch/CabalMesh-Roadmap.pptx
soffice --headless --convert-to pdf --outdir docs/pitch docs/pitch/decks/.build/CabalMesh-Project-Plan-1page.pptx
```

The one-pager is a page, not a slide: A4 portrait, its own geometry, no slide chrome. It ships
as PDF only — the intermediate `.pptx` stays in `.build/`.

## Rules the decks are written to

**Every capability carries a status chip.** `LIVE` / `IN PROGRESS` / `PLANNED` in the product
deck; `IN PROGRESS` / `NEXT` / `LATER` / `EXPLORATORY` in the roadmap. Nothing appears without
one, so a judge always knows which half of the sentence is shipped.

**Every LIVE claim names the file it was checked against.** The evidence slide is drawn from
[`docs/product-status.md`](../../product-status.md), which was written by reading the code.
Roadmap content comes from [`CabalMesh-Project-Plan.md`](../CabalMesh-Project-Plan.md).
When the audit changes, change the content object at the top of the build file — not the layout.

**Design follows [`src/ds/BRAND.md`](../../../src/ds/BRAND.md).** Pure black grounds, hairline
rules, corner registration ticks, uppercase micro-labels with wide tracking, one accent
(`#00E5FF`) kept under 5% of the surface. Acid green marks shipped, blood red marks a gap.
No filled buttons, no rounded corners, no gradients, no emoji.

**Fonts are system-safe on purpose.** Pixel Operator and IBM Plex Mono only exist here as
`.woff2`, which PowerPoint cannot embed, so the decks use Arial for display and Courier New for
evidence lines. Hierarchy is carried by weight, case and tracking instead of by typeface.

## Altitude

The roadmap deck is a **strategy** deck: what the product becomes, who hears about it, and what
each phase changes for the user and for the business. Engineering detail — file paths, tickets,
contract functions, environment blockers — deliberately stays in
[`CabalMesh-Project-Plan.md`](../CabalMesh-Project-Plan.md) and the one-page PDF, so the deck can
be shown to someone who does not read Rust.

## The pitch deck's two open fields

`build-pitch.js` marks anything only the founders can supply with a dashed accent frame and the
words `TO FILL` — customer conversations on slide 6, and names, roles and background on slide 7.
Market figures on slide 4 are public and carry their source on the slide itself
(ITU 2025, GSMA 2025, Mordor Intelligence, Grand View Research). Nothing on either slide is
invented: fill the frames in the `D` object at the top of the file and rebuild.

## Assets

- `src/ds/assets/logo/` — hero lockup (product cover), oracle emblem (roadmap cover), minimal mark
- `docs/pitch/src/icons2/` — 256px monochrome glyphs; the decks use the `_white` tone only
- `docs/pitch/src/deck-shadowbox.png`, `deck-nobody.png`, `deck-two-boxes.png` — Phase 2 device
  art, rendered from the `.svg` beside each one (vector, so it can be re-cut at any size).
  Regenerated by [`docs/pitch/render/`](../render/README.md) — Python emits the SVG, headless
  Chrome rasterises it at 2×.
- `docs/pitch/src/shadowbox.png`, `nobody-box.png` — superseded AI renders of the earlier
  four-device line. No deck references them any more; kept only until re-rendered.
